# Queen’s Collections – Landing Page  

This is a responsive landing page built for **Queen’s Collections**, an online store specializing in **women’s fashion, children’s clothing, household utensils, gifts, and souvenirs**.  

---

## Features  

- **Responsive Design** – Made easy for mobile, tablet, and desktop to open using queries.  
- **Stylish Layout** – Modern UI with gradient backgrounds, elegant fonts, and eye-catching visuals.  
- **Product Gallery** – Flexible grid layout to showcase products in rows of 3.  
- **Embedded Video** – Auto-adjusting video section for product promotions.  
- **Social Media Integration** – Direct links to WhatsApp, Instagram, and Telegram group.  
- **Why Choose Us Section** – Highlights brand values: Stylish & Versatile, Affordable & Quality, Nationwide Delivery.  

---

## Technologies Used  

- **HTML5** – Page structure  
- **CSS3 / Flexbox / Grid** – Styling & layout  
- **Bootstrap 5** – Responsive utilities and layout components  
- **Google Fonts** – Stylish typography (`Playfair Display` & `Poppins`)  
- **Font Awesome** – Icons (WhatsApp, Instagram, Telegram, etc.)
